# רואה חשבון

מערכת Google Sheets + Google Apps Script + RiseUp, מותאמת לקובץ **רואה חשבון - מערכת פיננסית**.

## גרסת הפיתוח הנוכחית

- `dev`: **Core V5.6.3**, **Dashboard V5.6.1** — התאמה למבנה הגיליון שנקרא ב־13/09/2026.
- `main`: הגרסה היציבה. גרסת הפיתוח אינה מותקנת אוטומטית בגיליון.
- בדיקות מקומיות עברו; נדרשת הרצה ובדיקה ידנית ב־Apps Script לפני קידום ל־`main`.

## הקבצים המלאים להעתקה

1. [src/Code.gs ב־dev](https://github.com/giladshai-blip/roe-heshbon/blob/dev/src/Code.gs) — להחליף את תוכן `Code.gs`.
2. [src/Dashboard.gs ב־dev](https://github.com/giladshai-blip/roe-heshbon/blob/dev/src/Dashboard.gs) — להחליף את תוכן `Dashboard.gs`.

לאחר החלפת **שני הקבצים** ושמירה: להריץ `setupV56`, אחריו `syncRiseUpHistory12MonthsV5`, אחריו `runV5Now` ולבסוף `healthCheckV5`. אלה שמות תאימות קיימים; `setupV56` מתקין את V5.6.3.

יש לקרוא קודם את [הוראות ההתקנה והחזרה לאחור](docs/install-v5.6.3.md). אין להשאיר עותק נוסף של Core או Dashboard באותו פרויקט Apps Script.

## מה השתנה

- `cashflowDate` ממופה לעמודת `cashflowMonth`; שדות תשלומים תואמים לתיעוד RiseUp.
- כיוון העסקה מגיע מ־`isIncome`, ללא ניחוש לפי סימן הסכום.
- `firstSeenAt` בעמודה U נשמר; סטטוס הכפילות בעמודה V מחושב ממפתח העסקה.
- יתרת העו״ש אינה כוללת ימים עתידיים ואינה מציגה מידע חסר כאפס.
- שורת שנה 1 בתוכנית 5 השנים מתחילה מיתרת העו״ש, תוך שמירת הנחות המודל הקיימות.
- יומן הסנכרון נכתב לפי כותרות; התקציב נבדק לפני החלפתו; עדכוני תנועות נשארו בכתיבה מרוכזת.
- הדשבורד אינו מציג מידע חסר כמצב תקין; חלון 30 הימים מחייב כיסוי מלא; זיהוי הכרטיס בעל היחס הגבוה ביותר תוקן.
