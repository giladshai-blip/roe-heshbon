# רואה חשבון

מערכת פיננסית משפחתית מבוססת Google Sheets, Google Apps Script ו־RiseUp API.

## גרסה מאושרת

**`core-1.0.0`** היא גרסת ה־Release המאושרת ב־`main`.

החל ממספור זה קיימת גרסה אנושית אחת למערכת. המזהים הישנים של הרכיבים נשמרים לצורכי תאימות והיסטוריה בלבד:
- Apps Script Core: Legacy Build ID `V5.9.0`
- Dashboard: Legacy Build ID `V5.8.0`
- Gabi Agent: Legacy Build ID `0.7.2`

מקור האמת המכני לגרסה המאושרת הוא `release.json`.

## מדיניות גרסאות

- גרסה מאושרת ב־`main` מתחילה תמיד ב־`core-`.
- גרסת פיתוח ב־`dev` מתחילה תמיד ב־`dev-`.
- קידום שומר על המספר ומחליף רק קידומת, לדוגמה `dev-1.1.0` → `core-1.1.0`.
- מזהי Legacy אינם גרסת Release פעילה ואינם מיועדים להצגה למשתמש.

## Apps Script בגרסה המאושרת

- `src/Code.gs` — מנוע פיננסי, סנכרון, תחזיות, אימות, Health Check וטריגרים.
- `src/Dashboard.gs` — Dashboard מאושר.

שמות פונקציות ה־Legacy נשמרים ב־`core-1.0.0` כדי לא לשבור טריגרים או התקנות קיימות. שכבת שמות ידידותית חדשה נבדקת ב־`dev` ותיכנס ל־`main` רק לאחר אישור ובדיקות Runtime.

## שחזור

`main` הוא מקור השחזור המאושר עבור ניסויי `dev`. הפקודה `שחזר` מחזירה את רכיבי הניסוי הפעיל לגרסה המאושרת האחרונה מ־`main` ולא לגרסת dev קודמת.

## אבטחה

אין לשמור PAT, סיסמאות, API keys או סודות בקוד או ב־GitHub. סודות נשמרים ב־Script Properties או במנגנון סודות מתאים בלבד.
