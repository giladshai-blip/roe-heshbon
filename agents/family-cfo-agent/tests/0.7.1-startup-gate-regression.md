# Family CFO Agent 0.7.1 — Startup Gate Regression

מטרה: לוודא שכל שיחה חדשה בפרויקט `רואה חשבון` מתחילה עם אתחול גבי לפני התשובה הראשונה, ולא עם תגובת ברכה גנרית.

## SG-01 — היי גבי
**Given:** שיחה חדשה בפרויקט `רואה חשבון`.
**Input:** `היי גבי`
**Expected:**
- זהות גבי פעילה.
- `docs/project-instructions.md` ב־`main` נקרא לפני התשובה.
- כאשר ההקשר פיננסי/כללי, מקור האמת `רואה חשבון - מערכת פיננסית` נבדק.
- מתבצעת בדיקת Freshness.
- התשובה אינה ברכת שלום בלבד.
- מוצגת תמונת מצב כנדרש בהנחיית הפרויקט, או מצוין במפורש איזה מקור לא היה נגיש.

## SG-02 — היי
**Input:** `היי`
**Expected:** אותה התנהגות כמו SG-01. אין לדרוש מהמשתמש לכתוב שוב `גבי`.

## SG-03 — בוקר טוב
**Input:** `בוקר טוב`
**Expected:** Startup Gate לפני התשובה הראשונה.

## SG-04 — מה המצב
**Input:** `מה המצב`
**Expected:** Startup Gate + תמונת מצב פיננסית עדכנית לפי מקור האמת.

## SG-05 — תזרים
**Input:** `תזרים`
**Expected:** Startup Gate + קריאת מקור האמת + תזרים עדכני. אין להשתמש בנתון ישן מזיכרון במקום מקור האמת.

## SG-06 — מקור אמת לא נגיש
**Given:** אין גישה זמנית ל־Google Sheet.
**Input:** `היי גבי`
**Expected:** גבי עדיין קורא את ההנחיה הראשית, אינו ממציא יתרה או תזרים, ומציין בקצרה שהמקור הפיננסי לא נגיש/דורש רענון.

## SG-07 — מידע מוכר
**Given:** כרטיס/חשבון כבר ממופה במקור האמת.
**Input:** שאלה קצרה המתייחסת אליו.
**Expected:** reuse למיפוי הקיים; אין לבקש מגלעד להזכיר את פרטי הישות מחדש.

## SG-08 — איסור Greeting-only
**Input:** `היי גבי`
**Fail condition:** תשובה בסגנון `היי גלעד, מה תרצה לעשות?` ללא Startup Gate כאשר ההקשר שייך לפרויקט.

## קריטריון קבלה
PASS רק אם SG-01 עד SG-08 עוברים.

בדיקת קבלה חיה מומלצת: לפתוח שיחה חדשה בפרויקט ולשלוח בדיוק `היי גבי`.
