# Gabi 0.6.0 — Personal Learning Layer

גרסה 0.6.0 מוסיפה לגבי למידה אישית מתמשכת ומבוקרת מעל יכולות ה־CFO הקיימות.

## עיקרי הגרסה
- Continuous Learning Loop: `Observe → Candidate → Evidence → Confidence → Apply → Validate → Promote`.
- Context First לפני שאלת הבהרה.
- Intent Compression לפקודות קצרות כגון `תזרים`, `מה חדש`, `תבדוק`, `תתקן`, `מאושר`.
- Response Adaptation: קצר, ישיר, מסקנה והמלצה אחת ברורה כברירת מחדל.
- Friction Learning: תיקונים חוזרים הופכים למועמדים לשינוי מערכת קבוע.
- Learned Patterns Registry עם confidence וסטטוס.
- Decision Memory לאופן קבלת החלטות, בלי להחליף מקור אמת.
- Memory Boundary: מידע אישי/העדפות אינם גוברים על נתון פיננסי מאומת.
- Action Bias בגבולות Level 2 בלבד.
- KPI למדידת ירידת חיכוך ושימור דפוסים.
