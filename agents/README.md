# Agents — רואה חשבון

## ארכיטקטורה
`family-cfo-agent` הוא סוכן־העל היחיד שמחזיר לגלעד החלטה פיננסית סופית.
מתחתיו פועלים Sub-agents לפי תחום, וכל Sub-agent משתמש ב־Skills קיימים לפי הצורך.

היררכיה:

`Family CFO → Sub-agent תחומי → Skills`

כללי הניתוב המלאים נמצאים ב־`agents/family-cfo-agent/SUBAGENTS.md`.

## family-cfo-agent
הסוכן הראשי של המערכת הפיננסית.

תפקידו:
- לקרוא את ההנחיה המרכזית מ־`docs/project-instructions.md` שב־`main`.
- להשתמש בקובץ `רואה חשבון - מערכת פיננסית` כמקור האמת.
- לנתב ל־Sub-agent מתאים או ישירות ל־Skill כאשר אין צורך בשכבת ניהול נוספת.
- לבצע Match → Update → Create ו־anti-double-counting.
- לאחד ניתוחים מתזרים, תקציב, אשראי, חובות, זכויות, פנסיה ובקרת מערכת.
- לזהות באופן יזום סיכונים והזדמנויות כאשר מתקבל נתון חדש או מתבצע ניתוח.
- להחזיר החלטה אחת ברורה עם רמת ודאות ופעולה הבאה.

## household-controller-agent
שכבת הבקרה והאמינות.
אחראי על נתונים חדשים, התאמות, כפילויות, סיווג חד־פעמי/חוזר, עדכון מקור האמת וחישוב מחדש של שכבות תלויות.

כלל מרכזי: `Match → Update → Recalculate → Verify`.

## cashflow-liquidity-agent
שכבת התזרים והנזילות.
אחראי על יתרת עו״ש מחושבת, 30 יום, שפל תוך־חודשי, סוף חודש, מועדי חיוב, מסגרת וסיכון להחזרות/חריגה.

## financial-planning-agent
שכבת התכנון והתרחישים.
אחראי על שאלות יכולת, תרחישים, שנה קדימה, תוכנית 5 שנים והשפעת החלטות גדולות.

## כללי הפעלה
כאשר יש נתון חדש וגם החלטה פיננסית:
`Controller → Cashflow (אם רלוונטי) → Planning (אם רלוונטי) → Family CFO`.

כאשר Skill יחיד מספיק, Family CFO רשאי להפעילו ישירות כדי להימנע מ־agent sprawl.

מצב יזום או Sub-agents אינם Runtime רקע בפני עצמם. ניטור מתוזמן או התראות עתידיות דורשים Automation/Runtime נפרד.
