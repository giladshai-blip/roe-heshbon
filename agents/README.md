# Agents — רואה חשבון

## family-cfo-agent
הסוכן הראשי של המערכת הפיננסית.

תפקידו:
- לקרוא את ההנחיה המרכזית מ־`main/docs/project-instructions.md`.
- להשתמש בקובץ `רואה חשבון - מערכת פיננסית` כמקור האמת.
- להפעיל את `financial-skill-router` ואת חבילת ה־Skills לפי הצורך.
- לבצע Match → Update → Create ו־anti-double-counting.
- לאחד ניתוחים מתזרים, תקציב, אשראי, חובות, זכויות, פנסיה ובקרת מערכת.
- להחזיר החלטה אחת ברורה עם רמת ודאות ופעולה הבאה.

גרסה נוכחית: `family-cfo-agent` V0.1 ב־`dev`.

הסוכן אינו Runtime חיצוני בפני עצמו; קובץ `AGENT.md` מגדיר את חוזה ההתנהגות והאורקסטרציה של המערכת. לפני קידום ל־`main` יש לעבור בדיקות תרחיש ורגרסיה.
