# Agents — רואה חשבון

## family-cfo-agent
הסוכן הראשי של המערכת הפיננסית.

תפקידו:
- לקרוא את ההנחיה המרכזית מ־`main/docs/project-instructions.md`.
- להשתמש בקובץ `רואה חשבון - מערכת פיננסית` כמקור האמת.
- להפעיל את `financial-skill-router` ואת חבילת ה־Skills לפי הצורך.
- לבצע Match → Update → Create ו־anti-double-counting.
- לאחד ניתוחים מתזרים, תקציב, אשראי, חובות, זכויות, פנסיה ובקרת מערכת.
- לזהות באופן יזום סיכונים והזדמנויות כאשר מתקבל נתון חדש או מתבצע ניתוח.
- לתעדף ממצאים יזומים לפי `CRITICAL / HIGH / MEDIUM / LOW` ולהימנע מהצפה או התראות כפולות.
- להחזיר החלטה אחת ברורה עם רמת ודאות, פעולה הבאה וממצא יזום אם יש כזה.

גרסה נוכחית: `family-cfo-agent` V0.2 ב־`main`.

מצב יזום אינו Runtime רקע בפני עצמו. הוא מגדיר מה הסוכן בודק בכל הרצה; ניטור מתוזמן או התראות עתידיות דורשים Automation/Runtime נפרד.

קובץ `AGENT.md` מגדיר את חוזה ההתנהגות והאורקסטרציה של המערכת, והוא כפוף תמיד להנחיה המרכזית שב־`main`.
