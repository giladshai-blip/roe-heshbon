# Gabi 0.7.2 — Explicit Activation Gate Regression

מטרת הבדיקה: לוודא שהסוכן `family-cfo-agent` מופעל רק כאשר גלעד כותב במפורש `היי גבי`.

## PASS — הפעלה

1. קלט בשיחה חדשה: `היי גבי`
   - גבי מופעל.
   - `docs/project-instructions.md` נקרא מ־`main`.
   - אם ההקשר כללי/פיננסי, מקור האמת נבדק לפני הצגת נתונים.

2. קלט בשיחה חדשה: `היי גבי, מה מצב התזרים?`
   - גבי מופעל.
   - Startup Gate של גבי רץ לפני התשובה.

3. שיחה התחילה ללא גבי; בהודעה מאוחרת יותר: `היי גבי`
   - גבי מופעל מאותה הודעה ואילך.

## PASS — אי־הפעלה

הקלטים הבאים בשיחה חדשה אינם מפעילים את גבי:
- `היי`
- `בוקר טוב`
- `מה המצב`
- `תזרים`
- `מה היתרה שלי?`
- שאלה פיננסית אחרת ללא הביטוי `היי גבי`
- בקשה טכנית ללא הביטוי `היי גבי`

בכל המקרים האלה:
- אין להפעיל את זהות `family-cfo-agent`.
- אין להריץ Startup Gate של גבי.
- אין להציג תמונת מצב פיננסית אוטומטית רק משום שהשיחה נמצאת בפרויקט.

## Persistence

לאחר שגבי הופעל באותה שיחה, הוא נשאר פעיל עד בקשה מפורשת של גלעד להפסיק לעבוד מול גבי או לעבור למצב אחר.

## FAIL

- גבי הופעל בלי שהביטוי `היי גבי` הופיע.
- `היי`, `בוקר טוב`, `תזרים` או שאלה פיננסית רגילה הפעילו Startup Gate.
- לאחר `היי גבי`, גבי לא טען את ההנחיה הקנונית לפני פעולה פיננסית רלוונטית.
