## שיטת מעבר
לכל שלב:
`Map → Owner → Shadow → Parity → Cutover → Deprecate → Health Check`.

ב־Shadow המנוע החדש מחשב במקביל לישן אך אינו מזין החלטות. Cutover מותר רק לאחר התאמה מלאה או פער מוסבר ומתועד.

- אותו עוגן עו״ש ותאריך אימות.

- התקנת Dashboard אינה משנה תוצאות Core.
- Rollback מתועד ונבדק.
