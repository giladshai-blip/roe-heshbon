# התקנת Core V5.6.3 ו־Dashboard V5.6.1

## לפני ההחלפה

שמור עותק של שני קובצי Apps Script הנוכחיים ושל הגיליון לפני הרצת התקנה. זו גרסת dev שנבדקה מקומית מול מבנה המערכת; טרם רצה בסביבת Apps Script החיה.

הקובץ מכוון למזהה הגיליון הקיים. אם בודקים על עותק, יש לעדכן **בשני קובצי הקוד** את `SPREADSHEET_ID` למזהה העותק. העתקת גיליון לבדה אינה משנה את המזהים הקבועים בקוד.

אין לשנות או לפרסם `RISEUP_PAT`. אם הוא כבר קיים ב־Script Properties, החלפת הקוד אינה מוחקת אותו. אין להתקין טריגר נוסף לצורך השדרוג.

## החלפה והרצה

1. פתח את פרויקט Apps Script המחובר למערכת.
2. החלף את **כל** תוכן `Code.gs` ב־[src/Code.gs ב־dev](https://github.com/giladshai-blip/roe-heshbon/blob/dev/src/Code.gs).
3. החלף את **כל** תוכן `Dashboard.gs` ב־[src/Dashboard.gs ב־dev](https://github.com/giladshai-blip/roe-heshbon/blob/dev/src/Dashboard.gs).
4. שמור. אין להשאיר Core נוסף בשם CodeV56 או עותק דשבורד המכיל אותן פונקציות/קבועים.
5. הרץ `setupV56`. השם נשמר לתאימות; הוא מתקין Core V5.6.3 והדשבורד רושם V5.6.1. רענן את חלון Google Sheets להצגת התפריט.
6. הרץ `syncRiseUpHistory12MonthsV5` לתיקון מיפוי החודש ושדות התשלומים בתנועות הקיימות.
7. הרץ `runV5Now` לסנכרון החודשים האחרונים והתקציב. סנכרון היסטורי לבדו אינו מרענן תקציב או את זמן הסנכרון המלא האחרון.
8. הרץ `healthCheckV5` וקרא את התקלות והאזהרות, לא רק את הכותרת.
9. השווה את אומדן העו״ש לבנק. אם נדרש עוגן חדש, השתמש ב־`promptVerifiedBankBalanceV5` והזן יתרה שנבדקה בפועל.

אין צורך להריץ `installHourlyTriggerV5` אם כבר קיים טריגר תקין של `syncRiseUpV5`. החלפת Code.gs שומרת את שם הפונקציה שאליו הטריגר מפנה.

## מה setupV56 משנה

- מוודא מבנה לפני שדרוג; אינו יוצר מחדש את המערכת או מסדר עמודות קיימות.
- כותרות הליבה בתנועות/תקציב, הרחבת יומן ושדה סטטוס כפילות.
- הפניית יעד כרית הביטחון, מקור פתיחת הגאנט ונוסחת העו״ש.
- C5 בתוכנית חמש השנים — רק אם היא עדיין הנוסחה השגויה שנצפתה.
- בנייה מחדש של **לוח המחוונים בלבד**, בהתאם לפריסה הקיימת; תרשימים מותאמים בלשונית הדשבורד יוסרו כחלק מהתקנת הדשבורד ללא שעונים.
- רישום גרסאות ולוג התקנה.

הנחות השכר, יתרות החובות, מועדי פירעון, תשואות, מסגרות ידניות ותזרים מתוכנן נשמרים. אין שכתוב גורף של חישובי התחזית ואין מילוי תאריכי firstSeenAt היסטוריים.
