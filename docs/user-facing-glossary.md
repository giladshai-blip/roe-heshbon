# מילון מונחים למשתמש — גבי / רואה חשבון

מטרת הקובץ: להבטיח שגלעד מקבל ניסוחים בעברית פשוטה וברורה גם כאשר מקור הנתונים משתמש בשמות שדות, סטטוסים או קודים טכניים באנגלית.

## כלל תצוגה מחייב

1. בתשובה למשתמש, **אין להציג שם שדה טכני גולמי במקום משמעותו**.
2. יש להציג קודם את המשמעות בעברית פשוטה.
3. כאשר יש ערך להסבר הטכני, אפשר להוסיף את שם השדה בסוגריים רק לאחר הניסוח בעברית, למשל: `מועד הופעה ראשונה במערכת (firstSeenAt)`.
4. אין לחשוף מזהים, hashes או קודי מערכת אלא אם הם נחוצים לבקשה, לאימות או ל-debugging.
5. אם מופיע מונח טכני שאינו במילון, גבי מתרגם אותו בהקשר לעברית פשוטה; אם הוא חוזר או משמעותי, דורון מוסיף אותו למילון.
6. בתוך קוד, לוגים, בדיקות ו-DEV מותר להשתמש בשמות הטכניים המקוריים. הכלל חל על **פלט משתמש**.

## שדות עסקה

| שם טכני | ניסוח למשתמש |
|---|---|
| `transactionId` | מזהה העסקה |
| `transactionDate` | תאריך העסקה |
| `cashflowMonth` | החודש שאליו העסקה משויכת בתזרים |
| `businessName` | שם בית העסק |
| `categoryLabel` | קטגוריה |
| `amount` | סכום |
| `direction` | הכנסה / הוצאה |
| `sourceType` | סוג אמצעי התשלום / מקור העסקה |
| `source` | מקור הנתונים / חברת הכרטיס או החשבון |
| `accountNickname` | שם החשבון או הכרטיס |
| `accountNumberHash` | מזהה מוסווה של החשבון או הכרטיס |
| `billingDate` | מועד החיוב בפועל |
| `isInstallment` | האם זו עסקת תשלומים |
| `installmentNumber` | מספר התשלום הנוכחי |
| `totalInstallments` | מספר התשלומים הכולל |
| `isPostponed` | האם החיוב נדחה |
| `commitmentId` | מזהה התחייבות קבועה |
| `actualType` | סוג העסקה בפועל |
| `categoryType` | סוג הקטגוריה |
| `lastSyncedAt` | מתי העסקה עודכנה לאחרונה בסנכרון |
| `firstSeenAt` | מתי העסקה הופיעה לראשונה במערכת |
| `duplicateStatus` / `סטטוס כפילות` | האם העסקה ייחודית או חשודה ככפילות |

## שדות וסטטוסים של סנכרון

| שם טכני | ניסוח למשתמש |
|---|---|
| `RiseUp lastUpdatedAt` | מועד העדכון האחרון שדווח מ-RiseUp |
| `cashflowHash` | חתימת בדיקה של נתוני התזרים |
| `UPDATED` | נמצאו נתונים חדשים או שינויים והמערכת עודכנה |
| `UPDATED_NO_HASH` | המערכת עודכנה, אך ללא חתימת השוואה זמינה |
| `SKIPPED_UNCHANGED` | הסנכרון רץ ולא נמצא שינוי בנתונים |
| `SUCCESS` | הפעולה הסתיימה בהצלחה |
| `WARNING` | הפעולה הסתיימה, אך קיימת אזהרה או נקודה לבדיקה |
| `ERROR` | הפעולה נכשלה או הסתיימה עם תקלה |
| `HISTORY_BACKFILL` | השלמת נתונים היסטוריים |
| `FORECAST_REFRESH` | רענון התחזית |
| `OFFICIAL_API` | עדכון ממקור רשמי חיצוני |
| `SELF_TEST` | בדיקה עצמית של המערכת |
| `SETUP` | התקנה או עדכון של רכיב מערכת |

## דוגמאות ניסוח

במקום:
> `firstSeenAt: 17/09/2026 06:19`

כתוב:
> **העסקה הופיעה לראשונה במערכת ב-17.09.2026 בשעה 06:19.**

במקום:
> `SKIPPED_UNCHANGED`

כתוב:
> **הסנכרון רץ, אבל לא נמצא שום שינוי בנתונים.**

במקום:
> `lastSyncedAt: 17/09/2026 06:19`

כתוב:
> **העסקה עודכנה לאחרונה בסנכרון ב-17.09.2026 בשעה 06:19.**

## בעלות ותחזוקה

- **גבי** אחראי להשתמש במילון בעת הצגת מידע למשתמש.
- **דורון** אחראי לתחזק ולהרחיב את המילון כאשר נוספים שדות, סטטוסים או קודי מערכת.
- המילון הוא שכבת תצוגה בלבד ואינו משנה את שמות השדות בקוד או במקור הנתונים.
